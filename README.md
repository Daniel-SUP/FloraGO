# FloraGO

## 🌸 О проекте

**FloraGO** — это веб-приложение магазина цветов с каталогом, личным кабинетом, избранным, корзиной и админ-панелью. Пользователь может зарегистрироваться, войти, заказать букет, добавить товары в избранное и оформить заказ.

## 🎯 Целевая аудитория  
- Люди, заказывающие цветы для подарков  
- Клиенты, которым нужна быстрая доставка  
- Покупатели, выбирающие букеты онлайн  
- Организации, оформляющие корпоративные заказы  
- Администраторы, управляющие ассортиментом  

## 🔑 Ключевой функционал  
- Регистрация и вход пользователей  
- Личный кабинет с редактированием логина и телефона  
- Каталог букетов и цветочных композиций  
- Детальная страница букета  
- Избранное  
- Поиск по товарам  
- Корзина и оформление заказа  
- Админ‑панель для управления товарами  
- Проверка уникальности логина и телефона  
- Динамическая загрузка данных с сервера

# 🛠 Технологический стек

## 🌐 Frontend
### **1. Чистый JavaScript**
**Почему чистый JavaScript**
- **Нет лишней сложности.** React/Vue/Angular подходят для крупных SPA, но FloraGo — компактный магазин, где достаточно классического JS.  
- **Меньше зависимостей.** Приложение работает быстрее и загружается быстрее.  
- **Прямой контроль над DOM.** Удобно реализовывать динамические элементы: каталог, личный кабинет, поиск.
### **2. HTML + CSS**
**Почему HTML и CSS**
- **Простота и скорость разработки.** Для небольшого проекта интернет‑магазина нет необходимости использовать тяжёлые фреймворки.  
- **Полный контроль над версткой.** Можно быстро адаптировать интерфейс под нужный дизайн.  
- **Легко поддерживать.** Любой разработчик сможет быстро разобраться в структуре.
### **3. Fetch API** — обмен данными с сервером без перезагрузки  
**Почему Fetch API**
- **Современный стандарт.** Позволяет легко отправлять запросы на сервер без перезагрузки страницы.  
- **Не требует библиотек.** Нет необходимости подключать Axios или jQuery.

## 🖥 Backend
### **1. Node.js (Express)**
**Почему Node.js**
- **Высокая скорость обработки запросов.** Node.js работает на неблокирующей модели ввода‑вывода, что идеально для API.  
- **Один язык на фронте и бэке.** JavaScript везде — проще поддерживать проект.  
- **Большая экосистема.** Много готовых библиотек: bcrypt, express-session, MySQL драйверы.
- **Минималистичный и гибкий.** Позволяет быстро создать REST API без лишней сложности.  
- **Простая маршрутизация.** Легко реализовать маршруты: регистрация, вход, каталог, профиль.  
### **2. MySQL**
**Почему MySQL**
- **Реляционная структура.** Магазин — это чёткие сущности: пользователи, товары, заказы. MySQL идеально подходит.  
- **Надёжность.** MySQL используется в крупных проектах и отлично справляется с нагрузкой.  
- **Простые связи.** Можно легко связать товары, категории, пользователей.  
- **Поддержка хостингов.** MySQL есть почти везде: Railway, PlanetScale, VPS.
### **3. bcrypt**
**Почему bcrypt**
- **Безопасное хранение паролей.** bcrypt не просто хеширует пароль, а делает это с использованием соли, что делает невозможным использование радужных таблиц для взлома.  
- **Защита от brute‑force атак.** Алгоритм bcrypt намеренно “медленный”, поэтому перебор паролей занимает значительно больше времени, чем при использовании обычных хеш‑функций (MD5, SHA‑1, SHA‑256).   
- **Простая интеграция с Node.js.** Библиотека имеет удобный API (`hash`, `compare`), что ускоряет разработку и снижает вероятность ошибок.
### **4. express-session**
**Почему express-session**
- **Удобная авторизация.** Позволяет хранить данные пользователя между запросами.  
- **Безопасность.** Сессии не хранят пароль, только ID и роль.
### **5. Nodemailer**
**Почему Nodemailer**

- **Универсальность и гибкость настроек.** Библиотека поддерживает любые способы отправки писем (Gmail, Mailgun, SendGrid). Вы можете переключить провайдера почты в любой момент, изменив всего пару строк конфигурации.

- **Комплексная работа с контентом.** Nodemailer берёт на себя всю сложную рутину: он "из коробки" поддерживает отправку красивых HTML-шаблонов, вложение файлов (attachments) любого формата и даже автоматическое встраивание картинок в тело письма (inline images).

- **Безопасность и надёжность.** В библиотеку встроена поддержка безопасных соединений (SSL/TLS), а также механизмы защиты от инъекций в заголовки писем (Header Injection), что гарантирует, что ваши отправления не будут перехвачены или заблокированы спам-фильтрами из-за кривого форматирования.

> `Node.js` не устанавливается через `npm install` — его нужно установить отдельно.
## 🚀 Запуск проекта

1. Установите зависимости:
   ```bash
   npm install
   ```
2. Создайте файл `.env` рядом с `server.js` и добавьте настройки:
   ```env
   DB_HOST=localhost
   DB_USER=root
   DB_PASSWORD=your_password
   DB_NAME=flora_go
   SESSION_SECRET=your_secret
   PORT=3000
   SMTP_HOST=smtp.example.com
   SMTP_PORT=587
   SMTP_USER=your_email_login
   SMTP_PASS=your_email_password
   SMTP_FROM=from@example.com
   ```
3. Запустите сервер:
   ```bash
   node server.js
   ```
4. Откройте браузер:
   ```
   http://localhost:3000
   ```

> Если SMTP не настроен, код восстановления пароля выводится в консоль.

# 🗄 **Схема данных и API**
---

## **Модель User (таблица: `users`)**

| Поле | Тип | Описание |
|------|------|-----------|
| **id** | INT, PK, AUTO_INCREMENT | Уникальный идентификатор пользователя |
| **login** | VARCHAR | Логин пользователя |
| **password** | VARCHAR | Хеш пароля |
| **phone** | VARCHAR | Номер телефона |
| **role** | VARCHAR | Роль пользователя (например: `user`, `admin`) |
| **email** | VARCHAR | Электронная почта |
| **createdAt** | TIMESTAMP | Дата и время регистрации аккаунта |

### Особенности модели:
- Пароль хранится **только в виде bcrypt‑хеша**  
- Логин и телефон проходят проверку на уникальность  
- Роль определяет доступ к админ‑панели  

---

## **Модель Product (таблица: `products`)**

| Поле | Тип | Описание |
|------|------|-----------|
| **id** | INT, PK, AUTO_INCREMENT | Уникальный идентификатор товара |
| **title** | VARCHAR | Название цветка или букета |
| **price** | DECIMAL | Цена товара |
| **rating** | DECIMAL | Средний рейтинг |
| **reviews** | INT | Количество отзывов |
| **image** | VARCHAR | URL изображения товара |
| **description** | TEXT | Описание товара или состав букета |
| **category** | VARCHAR | Категория товара |
| **flower_type** | VARCHAR | Тип цветка |

### Особенности модели:
- Поддерживает хранение любых цветов и букетов  
- Поля `rating` и `reviews` позволяют реализовать сортировку по популярности  
- Изображения хранятся как ссылки
