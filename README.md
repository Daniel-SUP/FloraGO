# FloraGO

🌸 FloraGO 🌸

📋 Описание приложения:

FloraGO — это современный веб-сервис по доставке цветов, который позволяет пользователям быстро и удобно заказывать букеты онлайн. Платформа предоставляет каталог цветочных композиций с подробным описанием и возможностью оформления доставки в несколько кликов. Сервис ориентирован на удобство, скорость оформления заказа и приятный пользовательский интерфейс. FloraGO помогает дарить эмоции и радость близким людям независимо от расстояния.

🎯 Целевая аудитория

- Частные лица, желающие заказать цветы для близких, друзей или коллег.

- Люди, которым важна быстрая доставка и удобный онлайн-сервис.

- Компании, заказывающие цветы для мероприятий, поздравлений и корпоративных клиентов.

⚙️ Ключевой функционал:

1. Просмотр каталога букетов и цветочных композиций.
2. Фильтрация и поиск товаров по категориям, цене и типу цветов.
3. Подробная страница товара с описанием и фотографиями.
4. Добавление товаров в корзину.
5. Оформление заказа с выбором даты и адреса доставки.
6. Регистрация и авторизация пользователей.
