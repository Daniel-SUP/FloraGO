# FloraGO

# 🌸 **FloraGo — онлайн‑магазин доставки цветов**

## 📝 Краткое описание  
**FloraGo** — это современный веб-сервис по доставке цветов, который позволяет пользователям быстро и удобно заказывать букеты онлайн. Платформа предоставляет каталог цветочных композиций с подробным описанием и возможностью оформления доставки в несколько кликов. Сервис ориентирован на удобство, скорость оформления заказа и приятный пользовательский интерфейс. FloraGO помогает дарить эмоции и радость близким людям независимо от расстояния.  
FloraGo создан для тех, кто хочет быстро и удобно заказать цветы с доставкой на дом или в офис.

## 🎯 Целевая аудитория  
- Люди, заказывающие цветы для подарков  
- Клиенты, которым нужна быстрая доставка  
- Покупатели, выбирающие букеты онлайн  
- Организации, оформляющие корпоративные заказы  
- Администраторы, управляющие ассортиментом  

## 🔑 Ключевой функционал  
- Регистрация и вход пользователей  
- Личный кабинет с редактированием логина и телефона  
- Каталог букетов и цветочных композиций  
- Детальная страница букета  
- Избранное  
- Поиск по товарам  
- Корзина и оформление заказа  
- Админ‑панель для управления товарами  
- Проверка уникальности логина и телефона  
- Динамическая загрузка данных с сервера

# 🧭 Структура приложения

| Раздел | URL | Тип | Описание |
|--------|------|------|-----------|
| **Главная** | `/` | публичная | Приветствие, переход в каталог |
| **Аутентификация** | `/auth/*` | публичная | Вход, регистрация, восстановление пароля *(считается за 1 раздел)* |
| **Каталог букетов** | `/catalog` | публичная | Динамический список букетов |
| **Детальная страница букета** | `/catalog/:id` | публичная | Фото, состав, цена, оформление |
| **Личный кабинет** | `/profile` | приватный | Просмотр и редактирование данных пользователя |
| **Избранное** | `/favorites` | приватный | Сохранённые букеты |
| **Поиск** | `/search` | публичная | Динамический поиск по букетам |
| **Корзина** | `/cart` | приватный | Добавление товаров и оформление заказа |
| **Админ‑панель** | `/admin` | приватный | Управление товарами и пользователями |

# 🛠 Технологический стек

## 🌐 Frontend
- **Чистый JavaScript** — лёгкий, быстрый, подходит для небольших проектов  
- **HTML + CSS** — адаптивная верстка  
- **Fetch API** — обмен данными с сервером без перезагрузки  

## 🖥 Backend
- **Node.js (Express)** — удобный фреймворк для REST API  
- **MySQL** — реляционная база данных для хранения пользователей и букетов  
- **bcrypt** — безопасное хеширование паролей  
- **express-session** — авторизация через сессии  

## ☁ Инфраструктура
- **Frontend** — GitHub Pages / Vercel  
- **Backend** — Render / Railway / VPS  
- **База данных** — MySQL (PlanetScale / Railway / локальный сервер)

# 🎨 Визуальное проектирование интерфейса

Ниже — описание всех страниц в едином формате.

---

## **Страница: Главная (/)**  
**Тип доступа:** публичный  

### Основные блоки:
1. **Шапка:** логотип FloraGo, меню (Главная, Каталог, Войти), аватар (если авторизован)  
2. **Блок приветствия:** заголовок, кнопка «Перейти в каталог»  
3. **Секция “Популярные букеты”:** 6 карточек  
4. **Футер:** контакты, ссылки  

**Динамический контент:** GET `/api/items?popular=true`

---

## **Страница: Аутентификация (/auth)**  
**Тип доступа:** публичный  

### Основные блоки:
- Форма входа  
- Форма регистрации  
- Поля: логин, пароль, телефон  
- Проверка уникальности  
- Сообщения об ошибках  

---

## **Страница: Каталог (/catalog)**  
**Тип доступа:** публичный  

### Основные блоки:
- Список букетов  
- Фильтры (повод, цена, цветы)  
- Поиск  
- Пагинация  

**Динамический контент:** GET `/api/items`

---

## **Страница: Детальная (/catalog/:id)**  
**Тип доступа:** публичный

- Состав  
- Цена  
- Описание  
- Кнопка «Добавить в корзину»  

**Динамический контент:** GET `/api/items/:id`

## **Страница: Личный кабинет (/profile)**

- Телефон

**Динамический контент:** GET `/check_user_info`

---

## **Страница: Избранное (/favorites)**  
**Тип доступа:** приватный  

### Основные блоки:
- Список сохранённых букетов

---

## **Страница: Поиск (/search)**  
**Тип доступа:** публичный  

### Основные блоки:
- Поле поиска  
- Динамические результаты  

**Динамический контент:** GET `/api/search?q=...`

---

## **Страница: Корзина (/cart)**  
**Тип доступа:** приватный

# 🗄 Схема данных и API

## 📌 Модель User

| Поле | Тип | Описание |
|------|------|-----------|
| id | INT | уникальный идентификатор |
| login | VARCHAR | логин пользователя |
| password | VARCHAR | хеш пароля |
| phone | VARCHAR | номер телефона |
| role | VARCHAR | user/admin |

---

## 📌 Модель Bouquet (товар)

| Поле | Тип | Описание |
|------|------|-----------|
| id | INT | уникальный идентификатор |
| title | VARCHAR | название букета |
| description | TEXT | описание |
| price | INT | цена |
| image | VARCHAR | фото |
| flowers | VARCHAR | состав |

# 📡 Основные API‑эндпоинты

### 🔐 Аутентификация
- **POST /registr** — регистрация  
- **POST /login** — вход  
- **GET /check_user_info** — данные текущего пользователя  
- **POST /update_user_full** — обновление логина и телефона  

### 🌸 Букеты
- **GET /api/items** — список букетов  
- **GET /api/items/:id** — детальная информация  
- **POST /api/items** — добавить букет *(admin)*  
- **DELETE /api/items/:id** — удалить букет *(admin)*
